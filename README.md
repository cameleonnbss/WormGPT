## 🎮 Usage

1. **Launch** : `python WormGPTV2.py`
2. **Setup API Key** → Menu 3
3. **Choose Model** → Menu 2 (or keep default GLM 4.5 Air)
4. **Chat** → Menu 1
5. **Chat Commands** : `menu` (back), `exit` (quit), `clear` (clear screen), `reset` (clear history)
